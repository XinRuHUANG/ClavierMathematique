# Clavier Mathématique

An Android mathematical symbol keyboard built with Kotlin.

## Features

The keyboard organizes mathematical symbols into eight categories:

1. Arithmetic
2. Comparisons and relations
3. Greek alphabet
4. Set theory
5. Calculus and analysis
6. Mathematical logic
7. Linear algebra
8. Other symbols: probability, geometry, exponents, subscripts and delimiters

## Technologies

- Kotlin
- Android SDK
- Gradle
- Android Input Method Service (IME)

## Requirements

- JDK 17
- Android SDK
- Gradle wrapper
